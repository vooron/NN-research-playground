Neural Net Playground

Two classes of points, a small network, and every weight on screen. It starts with do-nothing weights: layer 1 copies the input (W = identity) and the output neuron splits the plane at x₁ = 0, a vertical line. The data’s gap is tilted, so start by turning that line (or rotating layer 1) to fix it. Then move the sliders under each layer to rotate, stretch and shift the space, switch the activation to see it bend, pick harder data, and press Train when you want gradient descent to find the weights.
